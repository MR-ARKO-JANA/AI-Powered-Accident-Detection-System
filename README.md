# APADS - AI-Powered Accident Detection System

This project consists of three main services:
1. **Backend**: Node.js/Express server.
2. **Frontend**: React application.
3. **AI Service**: Python-based accident detection service.

## 🚀 Getting Started

### Start All Services with One Command

To start all services simultaneously in a single terminal with unified logs, run:

```bash
npm start
```

(or `npm run dev`)

Alternatively, on Windows, you can double-click:
`start.bat`

### Prerequisites
- Node.js installed.
- Python installed with a virtual environment in `.venv`.

### Service Details
- **Backend**: `http://localhost:5000`
- **Frontend**: `http://localhost:3000`
- **AI Service**: `http://localhost:5001` (or as configured)
